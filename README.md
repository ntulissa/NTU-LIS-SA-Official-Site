# NTU LIS SA Official Site

國立臺灣大學圖書資訊學系系學會官方網站。

Official website of the Student Association, Department of Library and Information Science, National Taiwan University.

## 技術架構

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 4
- React Router 7
- 部署：Vercel

## 本機開發

需要 Node.js 24。

```bash
npm install      # 安裝套件（第一次或 package.json 有改動時）
npm run dev      # 啟動開發伺服器，打開 http://localhost:3000
npm run build    # 打包正式版到 dist/
npm run preview  # 預覽打包後的正式版
```
